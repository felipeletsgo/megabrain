# SKILL: REFLEXÃO

## 1. Objetivo

Analisar registros para identificar tendências, conflitos e possíveis relações.

## 2. Ativação

ATIVE quando a pergunta exigir análise de vários registros ou quando uma revisão pedir reflexão.

## 3. Procedimento

1. Defina a pergunta.
2. Defina o período.
3. Recupere evidências relevantes.
4. Verifique cobertura dos dados.
5. Procure recorrência.
6. Procure exceções.
7. Compare contextos.
8. Produza conclusão proporcional.
9. Indique incerteza quando necessária.

## 4. Regras

NÃO use um evento como padrão.

NÃO confunda correlação com causalidade.

NÃO produza conclusão identitária forte com pouca evidência.

PREFIRA observações verificáveis.

## 5. Saídas

- tendência;
- comparação;
- conflito;
- hipótese;
- pergunta para investigação futura;
- nenhuma conclusão.

## 6. Escrita

Use ASD-STE100 adaptado.

SEPARE evidência de interpretação.
