# SKILL: PROJETOS

## 1. Objetivo

Manter iniciativas organizadas que produzem um resultado.

## 2. Ativação

ATIVE para esforço com várias ações, resultado definido e estado acompanhável.

NÃO crie projeto para tarefa isolada ou ideia ainda não iniciada.

## 3. Estado

PREFIRA:

- `idea`
- `planned`
- `active`
- `blocked`
- `paused`
- `completed`
- `cancelled`
- `abandoned`

## 4. Procedimento

1. Identifique o projeto.
2. CONSULTE projetos existentes.
3. Resolva duplicatas.
4. Determine estado.
5. Defina resultado esperado.
6. RELACIONE objetivo, pessoas, tarefas, decisões, problemas e eventos.
7. REGISTRE datas relevantes.
8. ATUALIZE o projeto.

## 5. Regras

Um projeto DEVE ter propósito claro.

Projeto e objetivo NÃO DEVEM ser o mesmo registro.

PRESERVE mudanças relevantes de prazo e escopo.

Use `blocked` somente quando um impedimento impedir avanço.

## 6. Conclusão

Use `completed` quando o resultado esperado for alcançado.

REGISTRE resultado e data.

## 7. Recuperação

A skill DEVE permitir responder estado, participantes, bloqueios, decisões, prazos, próximas ações e resultado.

## 8. Escrita

Use ASD-STE100 adaptado.

MANTENHA o resultado claro.

PRESERVE mudanças.
