# SKILL: IDEIAS

## 1. Objetivo

Preservar ideias com potencial futuro sem transformá-las em compromissos.

## 2. Ativação

ATIVE quando o usuário apresentar uma ideia, possibilidade ou conceito que possa ter valor futuro.

## 3. Estado

PREFIRA:

- `captured`
- `exploring`
- `promoted`
- `discarded`

## 4. Procedimento

1. Identifique a ideia.
2. CONSULTE ideias semelhantes.
3. Preserve a formulação principal.
4. RELACIONE tema, problema, objetivo ou projeto quando útil.
5. REGISTRE origem e data.
6. ATUALIZE o estado quando a ideia evoluir.

## 5. Regras

Uma ideia NÃO é tarefa.

Uma ideia NÃO é projeto.

Uma ideia PODE gerar projeto ou decisão posteriormente.

NÃO crie obrigação a partir de ideia sem confirmação.

## 6. Escrita

Use ASD-STE100 adaptado.

PRESERVE a ideia sem inflar o compromisso.
