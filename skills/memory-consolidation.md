# SKILL: CONSOLIDAÇÃO DE MEMÓRIA

## 1. Objetivo

Criar conhecimento de nível superior a partir de várias evidências.

## 2. Ativação

ATIVE quando vários registros relacionados sustentarem síntese útil.

## 3. Procedimento

1. Defina o tema.
2. Recupere evidências relacionadas.
3. Verifique quantidade e diversidade de evidências.
4. Procure exceções e contradições.
5. Produza síntese proporcional.
6. REGISTRE como memória consolidada ou inferência.
7. RELACIONE todas as evidências relevantes.
8. REGISTRE confiança.

## 4. Regras

NÃO consolide ocorrência isolada como padrão.

NÃO apague evidências de origem.

NÃO transforme associação em causalidade.

Uma memória consolidada DEVE poder ser revisada quando novas evidências surgirem.

## 5. Estado

Uma consolidação PODE ser:

- `active`
- `superseded`
- `disputed`
- `retired`

## 6. Escrita

Use ASD-STE100 adaptado.

PREFIRA linguagem proporcional à evidência.
