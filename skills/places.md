# SKILL: LUGARES

## 1. Objetivo

Manter locais relevantes e suas relações.

## 2. Ativação

ATIVE quando um local tiver valor futuro para evento, pessoa, preferência, projeto ou planejamento.

## 3. Procedimento

1. Identifique o lugar.
2. CONSULTE lugares existentes.
3. Resolva nomes alternativos.
4. Registre tipo e localização quando conhecidos.
5. RELACIONE pessoas, eventos e projetos.
6. REGISTRE contexto útil.

## 4. Regras

NÃO crie lugar persistente para menção irrelevante.

NÃO invente endereço.

PREFIRA referência externa quando uma fonte primária de localização estiver disponível.

## 5. Escrita

Use ASD-STE100 adaptado.

MANTENHA nome, tipo e contexto consistentes.
